01 / System Topology

Architecture & End-to-End Module Collaboration

Two cooperating analysis runtimes connected over a per-instance, HMAC-authenticated stdio JSON-line pipe — eliminating port collisions, local socket exposure, and PIE base mismatches.

VulnHunter4Ghidra Hybrid Dual-Engine Architecture

Ghidra High P-Code SSA (Java) ⇄ Authenticated stdio JSON-Line Pipe ⇄ angr VEX + Lifecycle + Z3 SMT (Python)

Ghidra Native Workbench (Java 21)

  • • ProgramScanner extracts functions, resolved thunks & -O2 tail-call jumps on cancellable background Task threads.
  • • PCodeTaintAnalyzer runs SSA Varnode def-use + Phi-node propagation across all SLEIGH processors with zero Python dependency.
  • • VulnHunterProvider + TaintPathHighlighter synchronize Listing/Decompiler colors and persist triage into .gpr Bookmarks.

Isolated IPC & Hybrid Fusion Bridge

  • • EngineManager spawns a dedicated --stdio subprocess per Ghidra window with a 128-bit session token (zero port 13372 collisions).
  • • Redirects native C stdout (fd 1 → stderr) so VEX/Z3 C libraries never corrupt JSON-line RPC frames.
  • • Hybrid Merger promotes findings independently confirmed by both SSA and VEX to [HYBRID] high confidence.

VEX + Lifecycle + Z3 Core (Python)

  • • taint.py tracks registers, unified sp/bp stack slots & propagators (snprintf, atoi, strdup), suppressing .rodata constants.
  • • detectors.py runs stateful machines for CWE-415, CWE-416, CWE-476, inter-proc CWE-190, and stack OOB writes.
  • • verifier.py & sarif.py prune dead SMT branches and emit OASIS SARIF 2.1.0 with --baseline regression gating.
02 / Technical Differentiators

Six Engineering Highlights That Set It Apart

Designed from the ground up to solve the classic pain points of binary static analyzers: CFG-only false-positive floods, PIE address skew, -O2 tail-call blindness, and legacy alert fatigue.

HYBRID IR SSA ∩ VEX Fusion

Dual-Engine Cross-Verification & Offline Resilience

Combines Ghidra's type-rich Decompiler HighFunction SSA with angr's VEX IR and Z3 solver. Even on raw MCU ROM dumps without ELF/PE headers or machines without Python, P-Code SSA Only mode works natively out of the box.

DATA-FLOW Zero Constant FPs

Unified Stack-Frame & Constant-Aware Taint

Unifies rsp and rbp frame coordinates across compiler prologues, infers stack-slot intervals, propagates taint through snprintf/atoi/strdup, and automatically suppresses hardcoded .rodata format/command strings.

LIFECYCLE CWE-415 / 416 / 476 / 190

Stateful Pointer & Arithmetic Machines

Replaces naive free() pattern matching with true state machines: recognizes p = NULL and reallocation sanitization (zero false positives on clean free), tracks branch-guarded NULL checks, and catches inter-procedural integer overflows sizing allocations.

-O2 READY Tail-Call Jumpouts

Release-Build (-O2 / -Os) Optimization Resilience

Production binaries turn terminal calls (puts(p), second free(p), wrapper hops) into jmp/b tail-calls. Both ProgramScanner and iter_function_invocations model jumpout sites as first-class call transitions.

Z3 SMT Dead-Path Pruning

Bounded Z3 Symbolic Reachability Verifier

Hooks external PLT and Mach-O import stubs with symbolic summaries and runs bounded SimulationManager exploration to confirm satisfiable path constraints (verified: true) while pruning contradictory dead branches.

DEVSECOPS SARIF + Baseline

Differential CI Gate & Custom Rule Packs

Exports OASIS SARIF 2.1.0 with step-by-step codeFlows for GitHub Security & DefectDojo. Pass --baseline prev.sarif --fail-on high to mute legacy debt and block only newly introduced regressions.

05 / Quick Start

Up and Running in 60 Seconds

Use interactively inside Ghidra CodeBrowser or drop directly into GitHub Actions / GitLab CI.

1. Build Plugin & Install CLI
# Install Python engine & `vulnhunter` CLI
python3 -m venv .venv && source .venv/bin/activate
pip install -e .

# Build Ghidra 11.x extension (.zip in dist/)
export GHIDRA_INSTALL_DIR=/path/to/ghidra_11.x
gradle buildExtension -PGHIDRA_INSTALL_DIR=$GHIDRA_INSTALL_DIR
2. CLI, SARIF 2.1.0 & Baseline Gate
# Scan with IoT rules + Z3 verification → SARIF 2.1.0
vulnhunter report ./firmware.elf \
  --rules rules/embedded_iot.toml --verify \
  --format sarif -o vulnhunter.sarif

# Block CI only on NEW High/Critical regressions
vulnhunter report ./firmware.elf \
  --baseline baseline.sarif --fail-on high
